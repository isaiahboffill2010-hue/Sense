# ==========================================================================
# Python dependencies for the Phase 1 hardware test
# ==========================================================================
#
# READ THIS BEFORE RUNNING pip.
#
# Nothing in this project is installed with `pip install -r requirements.txt`.
# That is deliberate, not an oversight. See README.md for the full story.
#
# --------------------------------------------------------------------------
# 1. Raspberry Pi OS packages -> apt
# --------------------------------------------------------------------------
# Picamera2, OpenCV and pygame ship as tested apt packages built against the
# system libcamera, SDL and kernel headers. Installing them from pip instead
# is slow (it compiles from source on a Pi 3), often fails, and can leave you
# with a Picamera2 that cannot see libcamera at all.
#
#     sudo apt update
#     sudo apt install -y python3-picamera2 python3-opencv python3-pygame \
#                         alsa-utils python3-smbus i2c-tools espeak-ng
#
# espeak-ng provides the offline text-to-speech used for spoken
# navigation guidance. Without it the HUD says "Speech: FAIL" and
# everything else, beeps included, carries on normally.
#
# --------------------------------------------------------------------------
# 2. SunFounder robot_hat -> installed from SunFounder's git repository
# --------------------------------------------------------------------------
# The ultrasonic sensor is driven through SunFounder's official Robot HAT
# library. It is NOT on PyPI in a form that matches the board, so it must be
# installed from source with SunFounder's own installer:
#
#     cd ~
#     git clone https://github.com/sunfounder/robot-hat.git -b 2.5.x
#     cd robot-hat
#     sudo python3 install.py
#
# Do NOT `pip install robot-hat` - the PyPI name belongs to a different,
# unofficial fork.
#
# robot_hat pulls in its own GPIO dependency (RPi.GPIO), so this project no
# longer needs lgpio.
#
# --------------------------------------------------------------------------
# 3. Gemini vision (Phase 2)  ->  pip, and ONLY this one
# --------------------------------------------------------------------------
# This is the single genuine pip dependency in the whole project. It is pure
# Python, there is no apt package for it, and Google ships it on PyPI.
#
# Raspberry Pi OS Bookworm and newer block system-wide pip installs (PEP 668).
# Do NOT solve that with a plain virtual environment: a plain venv cannot see
# the apt-installed Picamera2 or the system-installed robot_hat, which would
# break Phase 1. Use one of these instead:
#
#   (a) user install, leaves everything else untouched  [recommended]
#         pip3 install --user --break-system-packages google-genai
#
#   (b) a venv that can still see the system packages
#         python3 -m venv --system-site-packages ~/sense-venv
#         ~/sense-venv/bin/pip install google-genai
#
# Verify before running the app:
#     python3 smoke_test_gemini.py
#
google-genai>=1.0.0
pocketsphinx>=5.0.0
#
# Do NOT install `google-generativeai` - that SDK is deprecated.
#
# --------------------------------------------------------------------------
# 4. Standard library (nothing to install)
# --------------------------------------------------------------------------
# argparse, array, collections, math, os, platform, subprocess, sys,
# threading, time, wave, pathlib
#
# --------------------------------------------------------------------------
# The entries below are listed for completeness only, for machines that are
# NOT running Raspberry Pi OS. They are COMMENTED OUT on purpose.
# --------------------------------------------------------------------------
#
# numpy>=1.24          # pulled in automatically by python3-opencv / picamera2
# opencv-python>=4.6   # use apt's python3-opencv on Raspberry Pi OS instead
# pygame>=2.1          # use apt's python3-pygame on Raspberry Pi OS instead
